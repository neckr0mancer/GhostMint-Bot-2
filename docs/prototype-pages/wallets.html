Sending is available from Telegram

There is no dashboard send route yet. /send on Telegram walks through wallet, amount, destination and a confirm screen, using the same spend caps and gas ceiling.

Export a keystore

The raw key never reaches your browser. The server decrypts the stored envelope and immediately re-encrypts it as a standard V3 keystore under your security password. Only that encrypted file is downloaded.

Limited to 2 exports per hour, shared with Telegram. Every attempt is written to the security audit log.

Create your first wallet

GhostMint generates the private key on the server, encrypts it immediately with AES-256-GCM, and returns only the public address. The key is never sent to your browser.
